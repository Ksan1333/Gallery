# Gallery アプリ仕様書

対象バージョン: 2.0.5  
文書バージョン: 2.0.5  
最終更新: 2026-09-11

## 2.0.5で確認した仕様

- ギャラリーの選択モード中は、メディアをタップするとビューアではなく選択状態を切り替える。
- 長押し選択は子タイルのクリック処理より先にタッチイベントを監視し、ドラッグ選択終了時に選択状態が残っていれば選択モードを維持する。
- レコメンド詳細パネルが開いている状態で戻る操作を行うと、パネルだけを閉じる。タグ編集が開いている場合は先にタグ編集を閉じる。
- Androidのステータスバーおよびナビゲーションバーは、通常画面・メディアビューア・ブックビューア・動画ビューアで常時表示する。メディアビューア設定の旧システムバー切替は廃止する。
- 長押しで選択を開始した時点で選択モードに入り、ドラッグ中はトップバーを固定してグリッドのタッチ座標を安定させる。
- アプリバージョンは versionCode 16 / versionName 2.0.5 とする。

## 変更対象ファイル

- `ui/component/GalleryGridView.kt`: 選択モード中のタップ判定、長押しイベント監視、ドラッグ終了時のモード復帰。
- `ui/screen/MediaViewerScreen.kt`: レコメンド表示中の戻る処理、システムバー常時表示。
- `ui/screen/BookViewerScreen.kt`: ブックビューアのシステムバー常時表示。
- `ui/screen/VideoFullscreenViewerScreen.kt`: 動画ビューアのシステムバー常時表示。
- `MainActivity.kt`: ルート遷移時のシステムバー常時表示。
- `ui/screen/AppSettingsScreen.kt`: 旧システムバー表示切替の削除。
