# Gallery アプリ仕様書

対象バージョン: 2.0.2  
文書バージョン: 2.0.2  
最終更新: 2026-09-07

## 2.0.2で確認した仕様

- ライトテーマのメディアビューアのレコメンド詳細パネルは、テーマのサーフェス色と可読な文字色を使用する。
- 動画専用全画面ビューアでは、画面左半分のダブルタップで設定秒数だけ戻り、右半分のダブルタップで設定秒数だけ進む。秒数は動画ビューア設定のシーク間隔を使用する。
- ギャラリー、フォルダ内ギャラリー、動画ギャラリー、ビューアのメディア列は、日付・サイズ・名前の同一ソート規則（名前の数字先頭優先、URIタイブレーク）を共有する。
- 配布物は versionCode 13 / versionName 2.0.2 の ABI 別 APK として保持する。

## 既存仕様

画面、データ設計、権限、バックアップ、AI 分析など 2.0.1 までの仕様は、過去版の
[APP_SPECIFICATION_v2.0.1.md](APP_SPECIFICATION_v2.0.1.md) を継承する。

## 変更対象ファイル

- `ui/state/MediaOrdering.kt`: ギャラリーとビューアで共有するメディア順序。
- `ui/screen/MediaViewerScreen.kt`: ライトテーマのレコメンド詳細背景。
- `ui/screen/VideoFullscreenViewerScreen.kt`: ダブルタップ前後シーク。
- `data/local/dao/MediaDao.kt`: Paging の名前順・URIタイブレーク。
