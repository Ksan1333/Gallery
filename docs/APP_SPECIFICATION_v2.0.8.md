# Gallery アプリ仕様書

対象バージョン: 2.0.8
文書バージョン: 2.0.8
最終更新: 2026-09-13

## 2.0.8で確認した仕様

- アプリ更新ではGitHub ReleasesのLatestから、端末の対応ABIに合うリリースAPKを選択する。
- Android 8以降で提供元別インストール許可がない場合は設定画面を開き、許可後にGalleryへ戻ると保留中の更新を自動再開する。
- ダウンロードしたAPKはパッケージ名、SemVer、現在のアプリより新しいこと、署名証明書の互換性をインストール前に検証する。
- 単一署名では証明書ローテーション履歴を許容し、複数署名では現在の署名者集合の完全一致を要求する。
- 署名が一致しない場合はシステムインストーラーを開かず、設定画面のバックアップ保存、現アプリのアンインストール、正式署名APKの新規インストール、バックアップ読込の順で移行案内を表示する。
- システムインストーラーは結果返却を要求して起動し、ユーザーのキャンセルまたはインストール失敗を更新画面へ表示する。OSによる最終確認操作は省略しない。
- APKは64 KiB単位で読み込み、進捗通知は表示百分率が変わったときだけ行う。
- APKの検証に失敗した場合は、ダウンロード途中ファイルと確定後の不適合APKを更新キャッシュから削除する。
- アプリバージョンは versionCode 19 / versionName 2.0.8 とする。

## 2.0.7で確認した仕様

- メディアのフォルダ移動完了後は、直前の移動をSnackbarの「元に戻す」操作で元の相対フォルダへ戻せる。履歴はアプリ実行中の直前1操作のみ保持する。
- ギャラリーのフォルダ一覧でフォルダまたはグループを選択し、確認後に配下メディアをゴミ箱へ移動できる。管理フォルダ情報とグループ定義も整理する。
- 本のフォルダ一覧で長押しによる複数選択と確認付きフォルダ削除を行い、配下の本をゴミ箱へ移動できる。
- フォルダ内のメディアまたは本が0件になった場合、フォルダ一覧へ自動的に戻る。
- 本のフォルダ内一覧では長押し選択と全選択を利用できる。
- アプリバージョンは versionCode 18 / versionName 2.0.7 とする。

## 2.0.6で確認した仕様

- AndroidリリースAPKはプロジェクトの既存Gallery署名鍵で署名する。署名設定がない環境ではリリースビルドを失敗させ、未署名APKを配布しない。
- ローカル署名値はルートの `signing.properties`（`signing.properties.example` 参照）から読み込み、秘密情報はGit管理対象に含めない。
- アプリバージョンは versionCode 17 / versionName 2.0.6 とする。

## 2.0.5で確認した仕様

- ギャラリーの選択モード中は、メディアをタップするとビューアではなく選択状態を切り替える。
- 長押し選択は子タイルのクリック処理より先にタッチイベントを監視し、ドラッグ選択終了時に選択状態が残っていれば選択モードを維持する。
- レコメンド詳細パネルが開いている状態で戻る操作を行うと、パネルだけを閉じる。タグ編集が開いている場合は先にタグ編集を閉じる。
- Androidのステータスバーおよびナビゲーションバーは、通常画面・メディアビューア・ブックビューア・動画ビューアで常時表示する。メディアビューア設定の旧システムバー切替は廃止する。
- 長押しで選択を開始した時点で選択モードに入り、ドラッグ中はトップバーを固定してグリッドのタッチ座標を安定させる。

## 変更対象ファイル

- `util/AppUpdateManager.kt`: インストール許可判定、APK署名検証、結果取得付きインストーラーIntent、失敗キャッシュ削除。
- `ui/screen/AboutScreen.kt`: 許可設定復帰後の自動再開とインストール結果表示。
- `MainActivity.kt`: 起動時更新ダイアログの自動再開、署名エラー、インストール結果表示。
- `res/values/strings.xml`: 更新失敗理由と署名移行案内。
- `AppUpdateManagerTest.kt`: 同一署名、証明書ローテーション、署名不一致、複数署名の互換性テスト。
