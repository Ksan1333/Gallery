# Gallery アプリ仕様書

対象バージョン: 2.0.9  
文書バージョン: 2.0.9  
最終更新: 2026-09-14

## 2.0.9で確認した仕様

- ギャラリーの日時表示・日時順並び替えは、MediaStoreのファイル変更日時（`DATE_MODIFIED`）を使用する。撮影日時（`DATE_TAKEN`）は使用しない。
- 通常ギャラリーの長押し選択の既定時間は380msとし、通常表示だけに追加していた220msの猶予は設けない。選択中または選択済みメディアへの長押しは従来どおり短縮する。
- 列数変更後は、変更前に表示していたメディアURIをスクロールアンカーとして同じ位置を復元する。
- 2列表示ではセル形状を固定し、サムネイルを`ContentScale.Fit`で全体表示する。縦横比の違いによる欠けは発生させない。
- ギャラリーの列変更・サムネイル確定時に隣接セルを動かすサイズアニメーションを行わない。

## 変更対象ファイル

- `data/repository/MediaRepository.kt`: MediaStore変更日時の読み込み。
- `ui/component/GalleryGridView.kt`: 長押し、列変更アンカー、2列サムネイル、レイアウト安定化。
- `ui/AppConstants.kt`, `ui/AppRoutes.kt`, `res/values/strings.xml`: 長押し既定値と日時ラベル。
