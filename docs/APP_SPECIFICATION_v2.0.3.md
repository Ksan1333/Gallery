最終更新: 2026-09-07

## 2.0.3で確認した仕様

- 動画再生開始時、音声トラックの先頭から最大8秒をバックグラウンドで解析する。解析はタイムアウト付きで、非対応形式や失敗時は音量を変更しない。
- RMS とピーク値から平均レベルが過大な動画を判定し、該当動画のアプリ内再生ゲインを初期値50%にする。端末全体のメディア音量は変更しない。
- 自動減衰された動画を全画面ビュワーで再生中は、左右端の上下音量ジェスチャーを初期50%からの相対ゲイン調整として扱う。通常動画では従来どおり端末のメディア音量を調整する。
- 解析結果は動画URI単位のメモリキャッシュを使い、同一動画を再度開いた時は再解析しない。
- 配布物は versionCode 14 / versionName 2.0.3 の ABI 別 APK として保持する。

## 変更対象ファイル

- `util/VideoVolumeAnalyzer.kt`: 音声サンプルの RMS/ピーク解析、タイムアウト、URI キャッシュ。
- `ui/screen/VideoFullscreenViewerScreen.kt`: 自動減衰判定と、減衰動画の相対音量ジェスチャー。
- `ui/screen/MediaViewerScreen.kt`: 通常の動画ビュワーへの自動再生ゲイン適用。
